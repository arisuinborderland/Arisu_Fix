ARISU RECOVERY SERVICE — CUSTOMER REVIEW SCREENSHOTS

The homepage contains six editable review screenshot slots:
- Slots 1–3 are shown first.
- Slots 4–6 appear after selecting “View All Reviews”.

HOW TO ADD YOUR OWN SCREENSHOT
1. Put your genuine customer screenshot inside this `reviews` folder. Example: customer-review-1.jpg
2. Open index.html in a text editor.
3. Search for `reviews/review-slot-1.svg` and change the matching image source to `reviews/customer-review-1.jpg`.
4. In the same card, remove `is-placeholder` from the button class and remove the `disabled` attribute. That enables tapping the screenshot to see it full size.
5. Change the screenshot's alt text to a short description that does not expose private details.
6. Repeat for the other slots as needed.

Each card's source and alt text are in index.html. Keep the provided SVG placeholder filenames unchanged unless you update index.html too.

PRIVACY / TRUST
- Do not use another business's testimonial as if it were feedback for Arisu.
- Get permission before displaying names, profile photos, private messages, or account details.
- Blur sensitive information and never expose passwords, login codes, recovery codes, or email/phone details.
- Do not invent ratings or customer experiences. Recovery outcomes vary and are not guaranteed.
