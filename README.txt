PROJECT STRUCTURE
-----------------
- HTML, CSS, JavaScript, and image assets at the project root are the editable source files.
- package.json and build.js provide the build command.
- vercel.json configures security headers and builds the site into dist/.
- .vercelignore excludes generated dist/ and README files from the source upload.
- dist/ is generated when running the build; it is intentionally not duplicated in this ZIP.

BUILD
-----
Requires Node.js 18 or newer.
1. Extract this ZIP.
2. Open a terminal in the ArisuV194 folder.
3. Run: npm run build
4. The public website files will be generated in dist/.

DEPLOYMENT
----------
For Vercel, deploy the project folder and let the configured build command generate dist/.
For static hosting that requires a prebuilt folder, run the build first and upload the contents
of dist/ as the site output. Do not mix files from older versions.
